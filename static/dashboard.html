Quick Setup Guide: Getting Meta Credentials

Step 1: Meta App

Go to developers.facebook.com, create an App of type Business. Add the Instagram Graph API product.

Step 2: Permanent Token

In Meta Business Suite > Business Settings > System Users, generate a token with `instagram_manage_comments` & `instagram_manage_messages`.

Step 3: Webhook Handshake

Set Callback URL to https://your-domain/webhook, enter your Verify Token, and subscribe to comments and messages.

05

Top Common Mistakes to Avoid

Avoid silent API failures
⚠️Disabled Messages in Facebook Page

In FB Page > Linked Accounts > Instagram, ensure "Allow access to Instagram messages in Inbox" is turned ON.

⚠️Using Expiring User Tokens

Graph Explorer tokens expire in 1-60 days. Always create a System User in Meta Business Suite set to Never Expire.

⚠️Testing in Development Mode

In Dev mode, DMs only work for registered App Testers. Switch your Meta App to Live Mode for public accounts.

⚠️Swapping Page ID & Instagram ID

`PAGE_ID` is strictly for your Facebook Page; `IG_BUSINESS_ACCOUNT_ID` is for Instagram. Use Test Connection to check.
